# TSBK07-Project

In this project, a spaceship simulator minigame was implemented. The goal was to construct a simple spaceship object that the player could control both horizontally and vertically within a scene. Additionally, a minigame was developed where players can fire projectiles at enemies moving towards the spaceship. Collision between enemies and the spaceship result in damage to the spaceship, while collision between the bullets and enemies result in enemies taking damage. The minigame ends when the spaceship's health decreases and reaches zero. 


## Getting started

To run this project, open the project directory in a terminal. Run the following commands:

$ make
$ ./project
